WFA Lunch Menu Editor

Builds the shared menu file used by every year-group morning tool. Load the current menu, make changes, download the file, then upload it to GitHub to overwrite menu.json.

Step 1 — Load the current menu

Pulls the live menu so you start from what's there now. You can also start from scratch or load a backup file.

Step 2 — Edit the weeks

Each week is a Monday date plus 5 days × 2 options (red column, green column). Use exactly the wording you want shown on the smartboard.

Tip: copy a similar week first, then change just the date.

Step 3 — Download and upload

Click below to download menu.json. Then go to GitHub and drag the file into the staff-learning-tools repo to replace the existing one.
